# 叙幕短片工作台

**说出你的故事，逐步把它制作成一部短片。**

叙幕是一款面向个人创作者的 Windows AI 短片制作工具。你可以口述或输入故事，生成剧本、人物设定、场景和分镜，再逐镜制作视频、调整剪辑并导出成片。每一步都可以预览、修改和选择历史版本，让创作过程与费用都看得见。

[使用说明](使用说明.zh-CN.md) · [验收记录](验收记录.zh-CN.md) · [反馈问题](https://github.com/clarke0922/AIGC/issues)

## 核心功能

| 功能 | 你可以做什么 |
| --- | --- |
| 口述编剧 | 录音或上传音频，编辑识别结果，再生成故事梗概、人物动机、冲突、结局与分场剧本 |
| 人物与场景 | 编辑人物外观、服装、声音描述和场景光线，生成或上传参考图 |
| 分镜制作 | 调整每个镜头的画面、对白、景别、运镜和时长，用参考图生成静帧与视频 |
| 自然语言微调 | 用“对白克制一些”“第三镜缓慢推近”等指令生成修改建议，预览差异后再采用 |
| 版本与连续性 | 保留历史内容和生成候选，上游设定变化时标记受影响镜头，选择局部重生成 |
| 预算管理 | 设置单价与项目预算，提交前预留费用，余额不足时拦截；按供应商账单核对实际支出 |
| 视频剪辑 | 调整镜头顺序、入出点、音量和是否参与成片，导出 MP4 与 SRT 字幕 |
| 本地工程 | 项目、素材和记录保存在本机，支持导出工程与费用记录用于后续剪辑 |

## 五步完成一部短片

**故事 → 角色与场景 → 分镜 → 视频 → 成片**

1. **讲故事**：新建项目，口述或输入想法。先预览生成的剧本，再选择采用。
2. **定人物与场景**：确定角色服装、声音描述和环境，生成或上传参考图。
3. **审分镜**：逐镜调整画面、对白与运镜，确认静帧后再生成收费视频。
4. **先试镜再开拍**：先做一个5秒对白镜头，检查人物、声音、口型和账单，通过后制作其余镜头。
5. **剪辑导出**：排序、裁剪、调音量，合成视频并下载成片和字幕。

内置「雨停之前」示例，包含人物、场景和六个镜头的剧本文本，可用于熟悉流程。

## 快速开始

### 已有 Windows 构建包

双击包内的 `叙幕短片工作台.exe`。本地源码工作区也可以双击 `启动叙幕.cmd` 打开已构建的版本。

移动应用时请复制整个 `win-unpacked` 文件夹。构建包包含运行环境与媒体处理工具，无需另装 Node.js 或 FFmpeg。仅克隆源码不会获得可执行程序，需要先按下方步骤构建。

### 从源码构建

准备 Windows x64、Git 和可运行 `npm.cmd` 的 Node.js 环境，在 PowerShell 中执行：

```powershell
git clone https://github.com/clarke0922/AIGC.git
cd AIGC
powershell -ExecutionPolicy Bypass -File scripts/setup-studio.ps1
npm.cmd run pack --prefix desktop
.\启动叙幕.cmd
```

首次安装需要网络。构建结果位于 `desktop/release/win-unpacked`；重新打包前请关闭该目录中正在运行的应用。

## 配置 AI 模型

应用使用你自己的云服务 API Key。文本、图片、分镜图片和视频可分别配置，语音转写使用独立的云识别连接。

在 **AI 配置 → 一键配置火山** 中填写 Key 后，可查询供应商模型目录：按用途只有一个候选时自动选中，多个候选时由你选择，也可手动填写控制台提供的完整 Model ID。列表查询失败时会提示原因；模型出现在目录中不等于账号已开通调用权限。

回到简易工作台的 **模型与费用设置**，选择连接、模型及对应单价，再保存项目设置。调用 ID 以供应商控制台为准，不将产品名称直接当作 API ID。

## 费用怎么控制

- 简易工作台首版项目预算上限为 **50元**，文本、图片、转写和视频任务均计入记录。
- 文本按每百万 Token、图片按每张、视频与转写按每秒填写费用上界；价格未知时不能提交。
- 每次生成先显示估算并预留费用，失败或状态不明的任务保留预留，核对账单后再释放。
- 视频超时且已有供应商任务编号时，继续查询原任务，避免重复提交。
- 通过参考图定稿、上传自有素材、局部修改和缩短镜头减少试错成本。

预算拦截依据你填写的价格计算，无法限制供应商扣款。先用5秒试镜核对真实账单，再决定后续制作规模。

## 本地保存与云端调用

默认数据目录为 `%APPDATA%/xumu-studio/backend`。完整备份请退出应用后复制该目录。

项目保存在本机；调用云模型时，会向所选供应商发送必要的故事、音频或参考图。请妥善保管本地密钥与备份，不要将数据目录提交到公开仓库。

## 当前版本范围

简易工作台聚焦 **30秒、16:9、最多2名主要角色、2个场景、6个镜头** 的个人短片。成片输出为720p MP4，字幕按镜头显示。

“电影感”是创作目标，实际画质、人物与音色连续性、口型和动作质量取决于模型与素材，需要逐镜验收。当前已验证本地制作流程、预算与版本逻辑及媒体合成，尚未完成真实30秒真人样片的完整视觉验收。
